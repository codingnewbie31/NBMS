# Overview

The information architecture defines how the different modules of NBMS are organized and connected. The goal is to make navigation predictable, efficient, and easy to understand.

---

# Primary Navigation

- Dashboard
- Inventory
- Production
- Orders
- Deliveries
- Employees
- Reports
- Settings

---

# Navigation Principles

- Keep navigation consistent across all pages.
- Group related features together.
- Minimize the number of clicks required.
- Display important information before secondary information.
- Maintain the same layout throughout the application.

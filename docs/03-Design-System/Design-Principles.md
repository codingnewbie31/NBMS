# Core Principles

- Clarity
- Consistency
- Efficiency
- Simplicity
- Scalability

Every screen should help users complete tasks quickly with minimal cognitive effort.

# Interface Goals

- Professional industrial appearance.
- Consistent spacing.
- Strong visual hierarchy.
- Reusable components.
- Minimal visual clutter.

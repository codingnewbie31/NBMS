# Primary User

## Operations Manager

The Operations Manager is responsible for managing the daily operations of Nashat Beverages.

### Responsibilities

- Monitor inventory
- Track production
- Manage customer orders
- Coordinate deliveries
- Review reports
- Supervise employees

### Goals

- Complete daily tasks quickly.
- Access important information at a glance.
- Reduce manual work.
- Avoid mistakes.

### Pain Points

- Too many clicks.
- Difficult-to-find information.
- Slow workflows.
- Inconsistent interfaces.

# Secondary User

## System Administrator

The System Administrator is responsible for maintaining and improving the system.

### Responsibilities

- Manage system configuration.
- Implement new features.
- Resolve bugs.
- Improve the user experience.
- Maintain system performance.

### Goals

- Keep the system reliable.
- Make future development easier.
- Ensure the application remains organized and maintainable.
